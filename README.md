# Cognifyz-Data-Analysis-Internship

This project was completed as part of the Data Analysis Internship at Cognifyz Technologies.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Data Visualization
- Data Analysis Techniques

## Tasks Completed

### Level 1

## Level 1 – Task 1: Top Cuisines Analysis
This task focuses on identifying the most common cuisines served by restaurants in the dataset. Using Pivot Tables in Excel, the frequency of each cuisine was calculated to determine the top cuisines offered by restaurants. Additionally, the percentage distribution of these cuisines was analyzed to understand which types of food are most popular among restaurants.
![Top Cuisines](task1_top_cuisines.png)



## Level 1 – Task 2: City Analysis
In this task, the dataset was analyzed to examine the distribution of restaurants across different cities. A Pivot Table was used to calculate the number of restaurants present in each city and to determine the average rating of restaurants in those locations. This analysis helps identify cities with the highest concentration of restaurants and better-performing locations.
![City Analysis](task2_city_analysis.png)


## Level 1 – Task 3: Price Range Distribution
This task analyzes how restaurants are distributed across different price categories. A Pivot Table was used to calculate the number and percentage of restaurants in each price range. A bar chart was created to visually represent the distribution, helping to understand whether most restaurants fall in lower, mid, or higher price ranges.
![Price Range](task3_price_range.png)


## Level 1 – Task 4: Online Delivery Analysis
This task examines the availability of online delivery services among restaurants. The dataset was categorized based on whether restaurants offer online delivery or not. Using Pivot Tables, the percentage of restaurants providing online delivery was calculated, and the average ratings of restaurants with and without delivery services were compared.
![Online Delivery](task4_online_delivery.png)

### Level 2

## Level 2 – Task 1: Ratings Analysis
This task focuses on analyzing the distribution of restaurant ratings in the dataset. The ratings were grouped into categories such as Excellent, Very Good, Good, Average, and Poor. Using Pivot Tables, the frequency of each rating category was calculated, and the average number of votes received by restaurants in each category was also analyzed.
![Ratings](task5_ratings_analysis.png)


## Level 2 – Task 2: Cuisine Combination
In this task, the dataset was analyzed to identify the most common combinations of cuisines offered by restaurants. Pivot Tables were used to count the number of restaurants serving each cuisine combination. The analysis also examined the average ratings of these combinations to determine which cuisine pairings are most popular and well-rated.
![Cuisine Combination](task6_cuisine_combinations.png)


## Level 2 – Task 3: Geographic Analysis
This task analyzes the geographic distribution of restaurants using the latitude and longitude coordinates provided in the dataset. A scatter plot was created in Excel to visualize restaurant locations. The visualization helps identify clusters of restaurants in specific regions and provides insights into areas with high restaurant density
![Geographic Analysis](task7_geographic_analysis.png)


## Level 2 – Task 4: Restaurant Chain Analysis
This task identifies restaurant chains by analyzing repeated restaurant names in the dataset. Pivot Tables were used to count how many outlets each restaurant chain has. Additionally, the average ratings of these chains were calculated to evaluate their overall customer satisfaction and popularity.
![Restaurant Chains](task8_restaurant_chains.png)
## Dataset
Restaurant dataset containing information about cuisines, ratings, price ranges, locations, and delivery services.

## Outcome
The analysis provided insights into cuisine popularity, restaurant distribution, rating patterns, and restaurant chains.
