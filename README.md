# Cognifyz Data Analysis Internship

Data Analysis & Visualization project completed during the Data Analysis Internship at Cognifyz Technologies.

## 📌 Project Overview

- **Internship:** Cognifyz Technologies (Data Analysis Intern)

- **Tools & Tech:** Python, Pandas, Matplotlib, Jupyter Notebook (`Cognifyz_Data_Analysis.ipynb`), MS Excel, Pivot Tables.
- **Deliverables:** Analytical charts (Level 1 Tasks 1-8) and dataset insights.
